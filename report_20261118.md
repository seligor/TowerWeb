# Отчёт о работе

## За последние 4 дня

### Поиск по коллекциям

Реализован поиск по всем основным коллекциям SecureTower: почта, мессенджеры, веб-активность, файловые операции, сетевые ресурсы, принтеры, буфер обмена, скриншоты, веб-камера, кейлоггер, устройства.

### Новые условия поиска

- Произвольный атрибут — с полным справочником полей и фильтрацией
- Произвольный запрос
- Файл и файловые операции
- Номер банковской карты, почтовый адрес, регулярное выражение
- Общие поисковые условия

### Типы поиска

Добавлен выбор типа поиска: обычный, по словарю, по цифровым отпечаткам, по банкам хэшей. Для каждого типа — свои параметры (словарь и порог срабатывания, банки и хэш-суммы).

### Точность результатов

Все запросы сверены с перехватами нативной консоли и приведены к её виду. Исправлен ряд расхождений, из-за которых выдача отличалась от консольной — в том числе по периодам, областям поиска и фильтрам.

### Менеджер регулярных выражений

Добавлено окно управления регулярными выражениями: системные и пользовательские, создание, редактирование, дублирование и удаление. Пользовательские выражения хранятся на сервере.

### Периоды

Приведены в порядок все варианты периода: «Сегодня», «Последние N дней», «Весь период», произвольный период. Границы учитывают часовой пояс, выдача больше не захватывает соседние дни.

### Просмотр документов

Исправлено отображение времени в переписках — теперь оно совпадает со списком документов и пересчитывается под часовой пояс зрителя.

### Диагностика

Улучшено журналирование: в журнал записывается весь запрос формы целиком, добавлена ротация файлов по дням. Это позволило быстро находить причины расхождений вместо догадок.

### Интерфейс

Исправлено окно менеджера регулярных выражений и оформление в тёмной теме.
